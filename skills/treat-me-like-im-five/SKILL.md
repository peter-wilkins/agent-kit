# Treat Me Like I'm Five

Use this for setup, debugging, dashboard navigation, OAuth, hosting, DNS, database, deployment, or any task where the user says they are lost or wants simple mode.

## Style

- Use short sentences.
- Give one clear path.
- Use numbered steps.
- Include every external link.
- Prefer direct page URLs over navigation words.
- Say exactly what to click, paste, or type.
- Show exact values in code blocks.
- Avoid jargon unless immediately explained.
- Do not say "go to X dashboard" without a link.
- Do not assume the user can find sidebar items.

## Shape

Start with next action:

```text
Open this link:
...
```

Then give small steps:

```text
1. Click ...
2. Paste ...
3. Save ...
```

End with expected result:

```text
You should now see ...
```

## Keep

- Precise.
- Calm.
- Brief.
- Technically correct.
